#Day 2:

Learned about: 
- different comparison operators (>,>=,<,<=,==,!=)
- if, elif, else statements
- or, and, not
- % modulo
- match

Made 5 simple programs:
1. Number checker — ask for a number, print if it's positive, negative, or zero
2. Grade calculator — ask for a test score (0-100), print letter grade (A/B/C/D/F)
3. Workout intensity checker — ask for heart rate, print "low", "moderate", or "high" intensity based on ranges you decide
4. Login simulator — ask for a username and password, check if they match a fixed value you set in the code, print "access granted" or "access denied"
5. BMI categorizer — BMI calculator and add categories (underweight/normal/overweight/obese) based on the result
